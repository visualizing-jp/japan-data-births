# データソース

「日本人はどれだけ子どもを産んできたか」探索ダッシュボードのための、データソース調査とデータ層の設計方針。
実装前の意思決定記録。調査日: 2026-09-06。軸は e-Stat API のメタ取得・公開の統計表表示IDで確認済み。

## 1. 結論

**厚生労働省「人口動態調査」（政府統計コード `00450011`）が一次情報源。**
出生は確定数の上巻表を軸ごとに使い分ける（単一の「全軸入り」表はない）。

| ビュー | 見せる核 | 一次ソース（statsDataId） |
| --- | --- | --- |
| 時代 | 出生数・出生率・TFR・出生性比・父母の平均年齢 | `0003411595` / `0003411609` |
| 年齢 | 母親の年齢（5歳階級）× 出生数・出生率 | `0003411599` |
| 地域 | 都道府県の出生率・合計特殊出生率 | `0003411597` / `0003411598` |

出典表記: 厚生労働省「人口動態調査」（e-Stat）。

## 2. 採用データセット（メタ確認済み）

### `0003411595` — 上巻 4-1 年次別にみた出生数・出生率・出生性比及び合計特殊出生率

- 軸: 出生数・出生率・出生性比(6) × 時間軸(123: 1899–2024)
- 採用: `00100` 出生数_総数 / `00130` 出生率 / `00140` 出生性比 / `00150` 合計特殊出生率
- 出生率は**人口千対**（‰）。出生性比は女児100に対する男児
- 1944–1946年は戦災等で欠落（表注）

### `0003411609` — 上巻 4-19 出生順位別にみた年次別父・母の平均年齢

- 軸: 表章(1) × 出生順位(4) × 父・母(2) × 時間軸(39: 1950–2024、近年毎年・それ以前は疎)
- 時代ビューでは出生順位 `00100` 総数の父・母平均年齢を採用（第1子以降の内訳は初期スコープ外）

### `0003411599` — 上巻 4-6 母の年齢（5歳階級）別にみた年次別出生数・百分率及び出生率

- 軸: 母の年齢(5歳階級)(26: 件数・百分率・率が同一軸に並ぶ) × 時間軸(27: 1950–2024)
- 年齢ビューの件数: `00120`〜`00180`（15〜49歳）
- 年齢ビューの率（女性人口千対）: `00290`〜`00350`（15〜49歳）
- 14歳以下・50歳以上・不詳・百分率は初期スコープ外（率の対応がない／物語の主軸外）

### `0003411597` — 上巻 4-3 都道府県別にみた年次別出生数・出生率

- 軸: 表章(2: 出生数/出生率) × 都道府県(49: 全国+47県+外国) × 時間軸(27)
- 地図の主指標は出生率。`外国`（`51000`）は除外

### `0003411598` — 上巻 4-5 都道府県別にみた年次別合計特殊出生率

- 軸: 表章(1) × 都道府県(48: 全国+47県) × 時間軸(29: 1960–2024)
- 地域ビューの補完指標

## 3. 除外・見送ったもの

| 候補 | 理由 |
| --- | --- |
| 総覧 `0003411561` の出生コード | 4-1 で出生性比まで揃うため二重化しない（コードは調査時に確認済み） |
| 出生順位×年齢クロス（4-17/4-18） | セル数が大きく、初期3ビューに不要 |
| 中巻の各歳×都道府県 | 初期スコープ外 |
| 出産場所・国籍・体重など | テーマ核（件数・率・TFR・母親年齢）の外側 |

## 4. 配信 cube

| ファイル | 次元 | 指標 |
| --- | --- | --- |
| `era.json` | metric × year | value（件数・‰・性比・人・歳） |
| `age.json` | age × year | count / rate |
| `geo.json` | metric × year × area | value / relative |

## 5. 想定ビュー

- **時代** (`era`): 長期の出生数・率・TFR・性比・父母の平均年齢
- **年齢** (`age`): 母親の年齢階級別の出生数・出生率
- **地域** (`geo`): 47都道府県の出生率・TFR と全国比
